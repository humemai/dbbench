# Contribute

## Tell us a setting is wrong

Open an issue on [humemai/dbbench](https://github.com/humemai/dbbench/issues) with:

- the engine and the version it applies to,
- the setting we use and the setting you recommend for this task,
- where your documentation says so.

We re-run the affected cells with your configuration on the same machine and publish them beside the earlier result, with the reason. The earlier result stays in the history.

## Add an engine, a query or a lane

Open an issue first describing the task and the engine's recommended setup. A new engine joins a lane when it can run the lane's full task list or when its gaps are declared.

## Report a problem with a result

Include the cell (lane, scale, workload, engine, version) and what you expected. If the answer digest differs from the one you get, say so: that is the most useful kind of report.
